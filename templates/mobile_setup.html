Open Assistant

Android — local Wi-Fi

  1. Build/install the included Android wrapper.
  2. Enter the address displayed above and tap Connect.
  3. Telephone links open the Android dialer.

Android or iPhone — web installation

  1. Deploy the assistant on a public HTTPS address.
  2. Android Chrome: select Install app.
  3. iPhone Safari: Share → Add to Home Screen.

HTTPS is required for reliable microphone and full PWA behavior. The local Wi-Fi address is intended for the Android wrapper and browser testing.

Updates

Run the newer desktop update installer. Local settings and contacts are preserved. The phone interface updates when it reconnects.
