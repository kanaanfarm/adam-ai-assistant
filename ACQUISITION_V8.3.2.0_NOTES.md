# Adam Acquisition v8.3.2.0

## Professional Meeting Autopilot + Live Register

- Adds three representative participation styles: Conservative, Balanced (default), and Proactive.
- Balanced mode can briefly intervene when participants appear to treat an unapproved consequential item as agreed, assign a material owner commitment, or create a material contradiction with the meeting record.
- Proactive mode can additionally flag clear technical/commercial risks and material owner actions/deadlines.
- Adam is instructed not to interrupt routine discussion merely to show knowledge. If a routed proactive event is not actually material after context review, Adam returns IGNORE and stays silent.

## Live Meeting Register

- Adds a retained live register for owner-approval items, information required, open actions/follow-ups, and risks/interventions.
- The register is evidence-bounded to paired participant/Adam exchanges and does not itself create approvals or execute actions.
- Clear Screen preserves the register; End Meeting / New Session resets it.

## MOM / Report 2.0

- Adds meeting title, project/reference, participants, and meeting date/time fields.
- Generated meeting reports include those fields without inventing missing metadata.
- Report evidence now includes the live register classification and owner-approval state.
- Replaces the HTML .doc workaround with a native `.docx` download endpoint using python-docx.
- Print / Save PDF remains available through the browser print flow.

## Preserved controls

- Adam remains a disclosed AI representative and does not impersonate Mohamad.
- Costs, variations, contractual commitments, payments, purchases, date changes, and other consequential actions remain blocked without separate owner approval.
- Multilingual understanding, natural professional dialogue, immediate topic-thread follow-ups, full-duplex listening, barge-in, retained meeting memory, and paired discussion history are preserved.
