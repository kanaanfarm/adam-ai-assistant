# Adam Acquisition v8.0.0 — Production & Commercial Release

- Establishes one dual-use codebase with two explicit operating modes: Personal Operation and Buyer Presentation.
- Personal Operation allows configured services only under Owner Approval and existing connector readiness boundaries.
- Buyer Presentation is synthetic-only and blocks private owner data and production connectors.
- Adds a final release manifest, ten-control release certification, and owner-facing Final Release Certification page.
- Preserves externalized credentials, Owner Approval, and the live-trading block.
- Does not automatically activate connectors, contact buyers, send messages, create meetings, or place trades.
- Existing Microsoft/Outlook, WhatsApp, memory, approval, and personal-assistant configuration remain unchanged.
